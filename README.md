# FAT_Quiz_App
Developed a Quiz Web Application using HTML, CSS, and JavaScript that dynamically presents multiple-choice questions, validates user responses in real-time, and displays final scores with restart functionality.

Application Description – Railway Signalling FAT Quiz

The Railway Signalling FAT Quiz Application is an interactive web-based quiz designed to test users’ knowledge of Factory Acceptance Testing (FAT) concepts in railway signalling systems. The application provides a simple and user-friendly interface where users can answer multiple-choice questions and receive immediate feedback on their responses.

The quiz dynamically displays questions and answer options using JavaScript, allowing for a smooth and responsive user experience. When a user selects an answer, the application highlights whether it is correct or incorrect and reveals the correct answer. At the end of the quiz, the user’s total score is displayed along with an option to restart the quiz.

This application is built using core web technologies:

HTML for structure
CSS for styling and responsive design
JavaScript for dynamic functionality and user interaction
🚀 Key Features
Multiple-choice question format
Real-time answer validation
Visual feedback for correct and incorrect answers
Score tracking and final result display
Restart quiz functionality
Clean and responsive user interface
🎯 Purpose

The main objective of this application is to help users:

Practice and assess their understanding of FAT concepts
Improve knowledge through interactive learning
Experience a simple quiz system built with frontend technologies
